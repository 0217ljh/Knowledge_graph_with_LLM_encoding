# 化学官能团分级方法

## 1. 化学官能团(1级) - > 大类(2级)

在化学官能团下，根据包含元素种类的不同进行划分，得到不同的官能团大类。同一官能团可以同时归属于不同的大类，例如：硝基化合物同时含有氮元素与氧元素，因此同时归属于含氮官能团与含氧官能团。

* **化学官能团(1级)**
  * 碳氢化合物(2级)
  * 含氧官能团(2级)
  * 含氮官能团(2级)
  * ...

## 2. 大类(2级) - > 子类物质(3级)

在官能团大类下，根据分子结构和化学性质的不同，可以划分得到不同的化学子类。一般情况下，若某分子已经属于同一大类下的子类物质，则应不属于同一大类下的其它子类物质。

* **含氧官能团(2级)**
  * 醚类(3级)
  * 醇类(3级)
  * 酮类(3级)
  * 醛类(3级)
  * 酯类(3级)
  * 羧酸类(3级)
  * 含氧芳香杂环(3级)
  * 含氧非芳香杂环(3级)  （_可考虑将该部分与含氧芳香杂环放在一起，甚至可不去除该类别，因为在非芳香情况下，多半可以直接归入醚/醇/酯等）_
  * 碳酸类(3级)
  * ...

## 3. 子类物质(3级) - > 特定官能团(4级)

在某个子类物质下，考虑到决定其相关化学性质的分子结构与存在形式可能具有差异，此处应进一步将子类物质下的特定基团结构取出。

* **醇类(3级)**
  * 羟基(4级)

* **腈类(3级)**
  * 腈基(4级)
  * 异腈基(4级)

* **含氧杂环(3级)**
  * 呋喃环(4级)
  * 苯并呋喃(4级)
  * 异常苯并呋喃(4级)
  * 𫫇唑(4级)
  * 苯并𫫇唑(4级)
  * ...

_关于含氧杂环以及杂环的相关内容，参见<https://zh.wikipedia.org/wiki/%E8%8A%B3%E9%A6%99%E7%8E%AF>。相关的专业知识可以维基百科为主。_

## 4. 特定官能团(4级) -> 红外振动吸收(5级)

* **羟基(4级)**
  * 自由羟基的O-H伸缩振动吸收，**3650-3600** (5级)
  * 分子间氢键O-H伸缩振动吸收，**3500-3200** (5级)
  * C-O伸缩振动吸收，**1200-1000** (5级)
  * O-H 变形振动吸收，**769-659** (5级)

_另注1：特定官能团(4级)可以同时连接不同的子类物质(3级)和大类(2级)，并不相斥。例如：𫫇唑(4级)就同时归属于含氧杂环(3级)和在含氮官能团(2级)下的含氮杂环(3级)。_

_另注2：某些特定官能团存在负相关表，即红外光谱某区间无吸收时，可以100%确定该官能团不存在。例如苯基(Phenyl)，当红外光谱存在：
1600-1450   可能为芳环的骨架振动吸收，
3100-3000   可能为C-H的不饱和(双键)伸缩振动吸收；
则该物质的分子结构中可能存在芳环。反之亦成立。_
